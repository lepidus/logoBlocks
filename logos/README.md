# Catálogo de logos

As imagens são distribuídas localmente; a galeria não consulta serviços externos.
Ao selecionar uma logo, o plugin grava uma cópia PNG de 150 px na revista.

## Fontes das imagens

Obtidas em 24/09/2026. SciELO e Crossref foram rasterizadas de SVG para PNG. A versão branca da BOAI recebeu fundo verde para manter a legibilidade em páginas claras. Os PNGs foram normalizados sem metadados e limitados a 600 px por dimensão.

## Adicionar itens ao catálogo distribuído

Inclua a imagem PNG, JPEG ou GIF nesta pasta e adicione uma chave estável em `catalog.json`, com `name`, `url` (HTTP/HTTPS ou vazio) e `file` (nome do arquivo nesta pasta). Respeite os limites de imagem descritos no README principal. O catálogo é mantido no código do plugin. O botão “Adicionar nova logo” continua cadastrando apenas na revista atual, sem alterar esta galeria compartilhada.
